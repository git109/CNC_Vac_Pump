KiCad schematic swap kit WeMos D1 Mini32 (ESP32) → P-NUCLEO-WB55 on the ST Morpho headers · KiCad 10.0.4 · total-beginner steps

Goal: replace the ESP32 (WeMos_D1_Mini32) symbol in Vac_Pump_Controller.kicad_sch with the STM32 P-NUCLEO-WB55, wired to its ST Morpho headers (CN7 / CN10). The peripheral subcircuits — LCD, relays, encoder, and the R1/R2/C1/C3 vacuum-sensor divider — are correct as-is and are not touched. Schematic-only; the PCB file is empty.

Why two connectors, not a board symbol? Your custom parts (WeMos, relay module, LCD) live embedded inside the schematic file — there's no separate symbol-library to extend. Rather than hand-build a Nucleo symbol (a lot for a first task) or hand-edit the 12,000-line schematic text (risky), we represent the dev board the honest way: as its two Morpho connectors, using KiCad's built-in generic connector. Nothing to install, and it mirrors how you physically wire it.

How the connection works (read once)

The schematic is a single flat sheet that connects things by net-label name, not by long wires. Every peripheral already carries its labels — the LCD chip-select wire says LCD_CS, the encoder says ENC_ChanA, the divider tap says Vacuum_Sig. Two points with the same label name are the same net. So the whole job is: put a label with the matching name on the correct Morpho pin. You do not route wires across to the peripherals — the name joins them.

Two nets intentionally change:

• LCD_MISO is dropped — write-only panel, no MCU MISO. Leave the LCD symbol's MISO pin unconnected (No-Connect flag, step 7) and delete any leftover floating LCD_MISO label.

• The MCU connects to Vacuum_Sig (the divided tap), never to the raw Vac_Sensor node. Nothing to do — just don't wire Vac_Sensor to the board.

Step-by-step in KiCad 10

(Or copy the PCB/Vac_Pump_Controller/ folder in Finder.) You can always git restore to undo.

1. Open the schematic

File → Open Project… → Vac_Pump_Controller.kicad_pro, then double-click Vac_Pump_Controller.kicad_sch. Navigation: scroll = zoom, middle-drag = pan, Esc = cancel tool, Ctrl+Z = undo, Home = zoom-to-fit. KiCad hotkeys act on whatever the cursor is hovering.

2. Delete the old ESP32 symbol

Find the WeMos D1 Mini32 block (pins named IO27, IO25, Txd…). Click its body, press Delete. The surrounding net labels can stay — we reuse those names. Delete any now-dangling wire stubs if you like (optional).

3. Place the two Morpho connectors

Press A (Add Symbol), search Conn_02x19_Odd_Even (library Connector_Generic), place it; press A again for the second. These are 2×19 = 38-pin parts — pin numbers 1–38 match the Morpho pin numbers exactly (odd 1,3,…37 one column; even 2,4,…38 the other).

4. Name them

Hover a connector, press E → Reference CN10, Value ST_Morpho_CN10. Second one → CN7 / ST_Morpho_CN7. Ignore any "no footprint" note — there's no PCB.

5. Wire stub on each used pin

For every table row: press W, click the connector pin endpoint (circle at the pin tip), drag ~2 squares into open space, click, Esc. Zoom in so you hit the exact pin number.

6. Attach the net labels

For every row except GND: hover the wire's free end, press L, type the exact name, place it, Esc. Copy capitalization verbatim: LCD_SClk, ENC_ChanA, Vacuum_Sig, LCD_BackLt, Vac_Pump, LCD_Vcc, 5Vdc. A typo makes a new disconnected net — ERC (step 9) will flag it.

7. Handle the dropped MISO

On the LCD module symbol, hover its MISO pin and press Q to drop a No-Connect (×) flag. Delete any leftover floating LCD_MISO label.

8. Ground & power

Press P (Add Power Symbol), search GND, place on a stub off CN7-20 and again off CN10-20 (all GND symbols share the GND net). LCD_Vcc on CN7-16 is the 3.3 V LCD feed; 5Vdc on CN7-18 is the 5 V rail (see caution).

9. Run ERC (your safety net)

Inspect → Electrical Rules Checker → Run.

  • Expected, harmless: ~60 "Pin not connected" warnings on the unused connector pins (we wire ~17 of the two connectors' 76) — normal for a dev-board-as-module. Ignore, or Q them for a clean report.
  • Must fix: any warning naming one of our nets (LCD/encoder/relay/ADC) — that's a name typo or a label off the wire end. Correct the spelling/placement.

10. Save & optional PDF

Ctrl+S. Then File → Plot… → PDF to eyeball the sheet. (Or ask me to run kicad-cli sch erc / export pdf on the saved file.)

Cautions

Schematic

  • Label names are exact & case-sensitive — the #1 mistake. Match the tables character-for-character.
  • Connector pin number = Morpho pin number. Go by the printed number (1–38), not screen position.
  • LCD_MISO is deliberately gone (write-only panel). No-Connect it.
  • Unused connector-pin warnings are expected — don't chase them.

Hardware / power

  • Field power: the external HS-40005 AC/DC supply's 5Vdc feeds the Nucleo 5V (E5V) pin, CN7-18 — which requires setting the board power-source jumper to E5V (UM2435 §6.4). On the bench, ST-LINK USB powers it instead; don't drive external 5 V into CN7-18 and USB at once unless the jumper is right, or you back-feed the ST-LINK.
  • 3.3 V is the Nucleo's on-board regulator (LCD_Vcc, CN7-16). Power the GC9A01 from this, never 5 V.
  • Avoid the Morpho-only pins the Arduino header hid: PA13/PA14 (SWD), NRST, PH3/BOOT0, and console PA2/PA3 (D0/D1).
  • Solder-bridge-shared pads (PA7=CN10-15, PA4=CN10-17, PA1=CN7-32) — board defaults to the pin we use; leave the bridges alone.

PCB — the .kicad_pcb is empty; this is schematic-only. If you ever lay out a board, assign footprints to CN7/CN10 first.
