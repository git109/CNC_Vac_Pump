How the SLS 1.6.1 Inspector is laid out

A selected widget's Inspector has these sections. Each value below is tagged with where it goes:

  • PROPSWidget Properties (top): the Name + widget-specific fields — Image: Asset, Rotation, Pivot X/Y, Scale; Label: Text.
  • TRANSFORMX, Y, Width, Height, Align (position/size; X/Y in px).
  • STYLEStyle Settings (bottom): add a local style to a Part (Main / Indicator), then set Background color, Radius, Text (font/color/spacing).

Every widget uses Align = CENTER, so the Transform X/Y are offsets from screen center (negative Y = up, negative X = left). "Size = content" → leave Width/Height on content so the image keeps its PNG size.

Font: courierBold — two steps

Copying the TTF into Assets is not enough — it only makes it a source. You must then generate the font in the Font Manager, or it won't appear in the label's Font dropdown (you'll only see the built-in Montserrat sizes).

  1. Add the source: drop Courier_BOLD.ttf into the project's assets/ (Assets → Fonts). Makes it selectable in the Font Manager; does not create a usable font yet.
  2. Generate it: open Panels → Font Manager → Create New Font with:
FieldValueNote
Font NamecourierBold
Select Font AssetCourier_BOLD.ttffrom the dropdown
Font Size30
Bpp4⚠️ original was 8 bpp — LVGL 9 rejects 8-bpp; 8 also blocks generation
Range0x20-0x7FASCII printable
  1. Click Create Font → it appears under Created Fonts.
  2. Assign it: vacLabel → STYLE → Text → Font → courierBold.
