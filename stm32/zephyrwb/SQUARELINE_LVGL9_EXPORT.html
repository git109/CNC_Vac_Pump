Re-exporting the SquareLine UI for LVGL 9.5 Step-by-step for the CNC Vacuum Pump Controller — written for first-time SquareLine users

The firmware ships a placeholder UI because the existing export (source/Vac_Gauge_V2/src/ui_lvgl/) targets LVGL 8.3 and won't compile against the LVGL 9.5 in this Zephyr workspace. This regenerates it for LVGL 9 into stm32/zephyrwb/src/ui/.

Your project (source/SquareLine_VacDisp/Sm_Disp.spj) is small — one screen, 8 widgets, 1 custom font, ~7 image assets — comfortably inside SquareLine's free tier (Personal license: 10 screens / 150 widgets).

0What we're producing

SquareLine exports a folder of C files (ui.c, ui.h, ui_Screen1.c, image .c files, the font, ui_helpers.*, filelist.txt). We want only those UI files — not a full template project — copied into stm32/zephyrwb/src/ui/.

Name contract — do not rename these widgets: the firmware refers to ui_Screen1, ui_GaugeFace, ui_Spinner1, ui_ledDarkImage, ui_ledRedImage, ui_Needle, ui_vacLabel, ui_redBugImg, ui_grnBugImg, and the font ui_font_courier_Bold. Keep the widget names exactly as they are so the generated ui_* symbols still match.

1Install SquareLine Studio

  1. Go to https://squareline.io/ → Downloads. Grab the macOS installer (Apple-Silicon build for your M-series Mac).
  2. Open the .dmg and drag SquareLine Studio to Applications. First launch: right-click → Open (clears the Gatekeeper warning for an unsigned app).
  3. Create a free account and sign in inside the app (login is required even for the free tier).
  4. Choose the Personal license — free, non-commercial, limited to 10 screens / 150 widgets. This project uses 1 / 8, so it fits. (A 30-day Trial unlocks Business features, but you don't need them.)

No other tools to install — SquareLine bundles its own font/image converters, and you do not need the LVGL source (we don't use SquareLine's compiler).

2Back up, then open the project

  1. Back up first — the upgrade edits the project in place: 
    cp -R source/SquareLine_VacDisp source/SquareLine_VacDisp.lvgl8.bak
  2. In SquareLine: File → Open Project… → select source/SquareLine_VacDisp/Sm_Disp.spj. It opens as an LVGL 8.3.11 project (board "Arduino with TFT_eSPI", 240×240).

You'll see the round gauge on the canvas, a Screens/Widgets tree on the left, an Inspector on the right, and an Assets panel (fonts + images).

3Prepare for LVGL 9 (before switching the version)

LVGL 9 dropped/renamed things SquareLine-8 projects rely on. Fix these first:

  1. Fonts. Assets panel → Fonts → select ui_font_courier_Bold → Modify. Ensure Bpp is 4 bit or lower (LVGL 9 removed 8-bpp fonts), then Modify/Update. This regenerates the font with the LVGL-9-compatible version macro.
  2. Animation Time. Select each widget and, in the Inspector, uncheck "Animation Time" wherever it appears (notably on ui_Spinner1). A left-over value can crash LVGL 9. (The spinner still spins; only the checkbox is the issue.)
  3. Color format. Project Settings (gear icon / File → Project Settings) → Display. If Color depth is 16-bit swap, change it to plain 16-bit — Zephyr's driver handles byte order, and a swapped format gives wrong colors. Leave resolution 240 × 240.

4Get onto LVGL 9 — the version is locked to the board template

The LVGL version is bound to the board/UI-kit template, not a free dropdown. This project's board is "Arduino with TFT_eSPI", an LVGL-8.3-only template — so its version list only shows 8.3.11 and there's no way to pick 9.x for it. (If new projects also only show 8.3, your SquareLine Studio is too old — you need ≥ v1.4.1 for LVGL 9; check Help → About and update from squareline.io.)

You get LVGL 9 one of two ways:

  • Recommended — create a fresh LVGL-9 project (see §8). At File → Create → New Project, choose a template that offers LVGL 9.x (a Desktop / generic project is simplest and LVGL-9-capable — confirm the LVGL version selector shows 9.x before creating), set 240 × 240 / 16-bit, then rebuild the 8 widgets. Reliable, and ~15 min for this 1-screen UI.
  • If available — swap the board template in place. Some SquareLine versions let you change an existing project's Board/template to an LVGL-9 board in Project Settings, after which the version follows to 9.x and your layout is preserved. The option is version-dependent and often missing — if you don't see it, use the fresh-project route.

Any 9.x export is source-compatible with the 9.5 runtime; SquareLine doesn't list 9.5 specifically. Once on a 9.x project, Save (⌘+S).

5Set the export path and options

  1. Project Settings → File export:
    • UI Files Export Path → …/CNC_Vac_Pump/stm32/zephyrwb/src/ui (create the ui folder if needed; or export elsewhere and copy in — step 6).
    • Object naming: leave the default (produces ui_<WidgetName>, e.g. ui_Needle). Do not switch to [Screen]_Name — that renames symbols and breaks the firmware contract.
    • Flat export: optional. The Zephyr build globs src/ui/**.c recursively, so either layout works.
  2. Export → Export UI Files. Do not use "Create Template Project" — that dumps an Arduino/PlatformIO scaffold we don't want.

You should now have ui.c, ui.h, ui_Screen1.c, the ui_img_*.c files, ui_font_courier_Bold.c, ui_helpers.*, and filelist.txt in stm32/zephyrwb/src/ui/.

6Wire it into the Zephyr build

  1. If you exported outside the repo, copy the files in: 
    mkdir -p stm32/zephyrwb/src/ui && cp -R ~/SquareLineExport/* stm32/zephyrwb/src/ui/
  2. Uncomment the two lines in CMakeLists.txt: 
    file(GLOB_RECURSE UI_SOURCES ${CMAKE_CURRENT_SOURCE_DIR}/src/ui/*.c)
target_sources(app PRIVATE ${UI_SOURCES})
  3. In src/main.c: #include "ui/ui.h", replace ui_placeholder() with ui_init(), and replace the placeholder ui_update() body with the real ui_* widget calls.

Hand this last part to me. Once the files are in src/ui/, tell me and I'll write the main.c integration against the real generated headers — that's where the 8.3→9 API renames (below) actually bite.

7LVGL 8.3 → 9 API changes you'll see

PurposeLVGL 8.3 (old firmware)LVGL 9
Rotate needle/bug imagelv_img_set_angle(obj, a)lv_image_set_rotation(obj, a)
Set label textlv_label_set_text(obj, s)(unchanged)
Show/hide the red LEDlv_obj_clear_flag(o, LV_OBJ_FLAG_HIDDEN)lv_obj_remove_flag(o, LV_OBJ_FLAG_HIDDEN)
Event target (only if you add events)e->targetlv_event_get_target(e)

Your ui_events.h was empty (no custom events), so the e->target change won't bite. lv_conf.h is irrelevant here — Zephyr configures LVGL via CONFIG_LV_*.

8Fallback: build a fresh LVGL 9 project

If §4's conversion corrupts the project, recreating this small UI is straightforward:

  1. File → Create → New Project. Board: any (e.g. "Arduino with TFT_eSPI" again — the board only affects the template we ignore). Set LVGL version = 9.x, Resolution 240 × 240, Color depth 16-bit (not swap).
  2. Recreate the widgets with the exact same names (see §0):
    • Add an Image widget for GaugeFace, Needle, ledDarkImage, ledRedImage, redBugImg, grnBugImg; a Label vacLabel; a Spinner Spinner1.
    • Import the PNGs from source/SquareLine_VacDisp/assets/ via Assets → Images → Add and assign each to its image widget.
    • Import the font (assets/Courier_BOLD.ttf) and set it on vacLabel.
    • Match positions/alignment to the originals (all centered; needle/bugs are rotated at runtime by the firmware, so their static angle is 0).
  3. Set the UI Files Export Path (§5) and Export → Export UI Files.

For a 1-screen UI this takes ~15 minutes and avoids all conversion quirks.
